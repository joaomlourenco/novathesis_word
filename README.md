## Welcome to the “NOVAthesis_word” DI-ADC template

This branch holds a single Word template for the **NOVA FCT / DI “ADC” cover** — the
Bachelor's (BSc) final-project report cover used when the project is carried out at a
partner company, with a slot for the company's logo — mimicking the visual produced by the
[NOVAthesis LaTeX template](https://novathesis.org)'s `nova/fct/di-adc` school
(`\ntsetup{school=nova/fct/di-adc}`).

Only a Portuguese version is available.

*If you are writing a regular NOVA FCT MSc or PhD thesis instead, see the
[`main` branch](https://github.com/joaomlourenco/novathesis_word/tree/main#readme).*

### Getting Help

**These templates are provided _as is_ with no support at all.**

However, the [“Discussions” page](https://github.com/joaomlourenco/novathesis_word/discussions) is open and users may interact and help each other there.  You may also ask for help in the [NOVAthesis Facebook Group](https://www.facebook.com/groups/novathesis), but remember to make it clear in your post that you are using the Word version of the template.
